Probability and statistics, in pure Go.
Measured in ULPs, drawn to the bit.

go-statistics is the statistics layer of the Go scientific stack built on go-ndarray: 32 univariate and 3 multivariate distributions with every method of a frozen SciPy distribution, descriptive statistics with NumPy's quantiles, and the statistical tests. Every distribution function is measured in ULPs against mpmath, with SciPy measured on the same points, and for the same seed the draws are SciPy's. No cgo, no assembly.

Why go-statistics

The statistics notebooks reach for, in one package.

Everything is in package stats: distributions, descriptive statistics, tests, the kernel density estimate and the bootstrap share one input type — a []float64 or a go-ndarray array — and one set of error kinds. Each Go call names the SciPy or NumPy call it corresponds to, and option structs have their defaults as the zero value.

🔔

24 continuous distributions

Normal, beta, gamma, chi-squared, Student t, F, noncentral chi-squared, log-normal, Weibull, Pareto, von Mises and more, each with pdf, cdf, sf, ppf, isf and their logarithms, moments, median, entropy, interval and support.

🎲

8 discrete, 3 multivariate

Bernoulli, binomial, Poisson, geometric, negative binomial, hypergeometric, discrete uniform and Zipf; the multivariate normal (with its CDF), Dirichlet and multinomial.

🌱

Draws from NumPy's generator

Rvs takes go-ndarray's random.Generator, which is NumPy's bit for bit, and makes the generator calls SciPy makes, so the same seed gives the same sample.

📐

Fits

FitXxx with fixed parameters: SciPy's closed forms to the bit, likelihood equations polished to full precision, and elsewhere a log-likelihood at least as high as SciPy's.

📊

Descriptive statistics

Describe, weighted means and variances, NumPy's 13 quantile methods, mode, skew, kurtosis, trimmed statistics, entropies, histograms with every bin rule, binned statistics.

🧪

Tests

t-tests (Student, Welch, trimmed), chi-squared and contingency tables, Fisher's exact test, Pearson, Spearman, Kendall, Kolmogorov–Smirnov, Mann–Whitney, Wilcoxon, Kruskal–Wallis, Shapiro–Wilk, Anderson–Darling, ANOVA, Levene, Bartlett.

🧮

On go-ndarray, across cores

stats.Map(x, d.CDF) applies a method to an array over every core, each element computed once, so the result does not depend on the number of goroutines.

📦

Pure Go, BSD-3-Clause

No cgo, no assembly. The accuracy budgets are enforced on amd64, arm64, 386, arm, riscv64, loong64, ppc64le and s390x.

Statistics for the Go scientific stack.

go-statistics computes on the arrays of go-ndarray and draws from its NumPy-exact generator, takes its special functions and optimisers from go-numerics, plots with go-plot, and a go-notebook cell can use all of them. Where the library is slower or less accurate than SciPy, the documentation says so.
